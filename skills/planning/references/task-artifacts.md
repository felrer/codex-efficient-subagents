# 작업 문서

## 세션과 brief

한 폴더는 특정 대상에 대한 한 작업 세션을 담습니다. 새 대상이나 별도 세션은 새 폴더에서 시작하고, 같은 세션의 별개 후속 작업은 같은 폴더의 다음 brief에 정리합니다. 진행 중인 brief에 대한 피드백은 같은 파일에 반영합니다.

planning이 brief를 작성하고 갱신합니다. designing은 승인된 내용을 설계 문서에 반영합니다. 인계할 때 세션 폴더와 현재 brief의 경로를 함께 전달합니다.

## 저장 위치

사용자가 brief 생성을 원하지 않으면 대화에 정리합니다. 그 외에는 프로젝트 `docs/README.md`의 `## Work Artifacts`에 설정된 `Work directory`를 사용합니다. 상대 경로는 프로젝트 루트를 기준으로 하며 외부 절대 경로도 지원합니다. 동기화 경로는 해당 경로 검증 지침을 적용합니다.

이미 알고 있는 세션 경로를 재사용합니다. 저장 위치가 없으면 대화에 정리하고 임의의 폴더를 만들지 않습니다. 작업 위치의 README는 사용 규칙을 담으며 세션별 목록을 누적하지 않습니다.

## 생성 명령

[work_artifacts.py](../scripts/work_artifacts.py)를 Python으로 실행합니다. 아래 `ROOT`, `TITLE`, `BODY`, `PATH`는 실제 경로와 값으로 바꿉니다.

- 새 세션과 첫 brief: `new-session --project ROOT --title TITLE --brief-file BODY`
- 기존 세션의 다음 brief: `new-brief --session PATH --brief-file BODY`
- 작업 위치 확인: `resolve --project ROOT`
- 향후 작업 위치 변경: `configure --project ROOT --directory PATH`

`BODY`는 내용이 있는 UTF-8 파일이며, `PATH`는 기존 세션 폴더의 절대 경로입니다. 제목은 영문·숫자와 하이픈으로 표현한 작업 대상 이름입니다. 임시 본문 파일은 생성에 사용한 뒤 정리합니다. 스크립트 소스를 매번 읽을 필요는 없습니다.

새 세션은 제목이 같아도 새 폴더를 만듭니다. 기본 식별자는 사용되지 않은 두 글자 접두사를 `AA`, `AB`, … 순서로 선택하고 폴더 번호는 `01`을 사용합니다. 보관된 폴더의 식별자도 예약된 것으로 취급합니다. 사용자가 코드를 지정한 경우에만 `--category UI`와 필요한 `--number 8`을 사용합니다. 작업 주제에서 임의의 분류 코드를 만들지 않습니다.

첫 문서는 `01-brief.md`입니다. 후속 문서는 해당 폴더의 `숫자-brief.md` 중 가장 큰 번호에 1을 더해 만듭니다. 번호는 최소 두 자리로 표시하고, 삭제된 번호를 채우지 않습니다. 기존 `02-plan.md` 등 다른 문서는 계산에서 제외합니다.

생성 결과는 `code`, `status`, `session`, `brief_number`, `brief`를 담은 JSON입니다. 반환된 경로를 사용하며 생성 실패를 완료로 보고하지 않습니다. 생성 명령은 호출마다 새 문서를 만들므로, 응답이 불명확하면 재실행 전에 파일 생성 여부를 확인합니다. 잠금 충돌은 기존 작업이 끝난 뒤 재시도하며 다른 작업의 잠금을 제거하지 않습니다.

기존 문서는 덮어쓰거나 이름을 바꾸지 않습니다. 내용 수정은 일반 편집 도구로 수행합니다. 작업 위치를 바꿔도 기존 세션의 절대 경로로 후속 brief를 만들 수 있습니다. `configure`는 설정과 관련 안내 링크를 갱신하며 기존 문서를 이동하지 않습니다.

## 검증

생성 명령이나 번호 할당을 변경하면 `python -B scripts/tests/test_work_artifacts.py`를 planning 스킬 폴더에서 실행합니다. Python 표준 라이브러리만 필요합니다. 테스트는 임시 디렉터리와 로컬 프로세스를 사용하고 종료 시 정리하며 실제 작업 문서를 변경하지 않습니다. 보통 수초가 걸리는 targeted contract 검사로, 새 세션·후속 번호·동시 실행·기존 데이터 보존과 설정 기능을 검증합니다.
